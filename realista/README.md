# Cancha 19 — reconstrucción desde cero

Esta carpeta es un proyecto Godot 4.4 independiente. No reutiliza el escenario anterior.

## Estado honesto
Esta es la nueva base de trabajo, no una versión final fotorrealista. El escenario inicial se genera con geometría procedural y sirve para fijar escala, encuadre y distribución urbana. Para alcanzar el aspecto de las referencias todavía hacen falta assets 3D de edificios/favela, texturas PBR, redes, graderías, vegetación, personajes riggeados y animaciones. No se debe presentar esta primera base como si ya fuera el resultado final.

## Abrir
1. Abrir Godot 4.4.
2. Importar el archivo `project.godot` de esta carpeta.
3. Ejecutar con F6/F5.

## Controles
- WASD o flechas: mover al jugador.
- Espacio: patear si está cerca del balón.

## Objetivo de arte
Favela brasileña densa y escalonada alrededor de una cancha de fútbol 5, arquitectura autoconstruida variada, fachadas con desgaste, balcones, rejas, cableado, azoteas y depósitos de agua. Iluminación de atardecer/noche y cancha con focos. Mantener rendimiento para Intel Iris Xe.
