# Asset research — visual prototype

This is a shortlist for evaluation, not a record of assets already imported.

## Surface materials and lighting

- [Poly Haven](https://polyhaven.com/) — photorealistic PBR materials, HDRIs and models. Its published assets are CC0; attribution is not required. Verify the license on each asset page before shipping.
- License: https://polyhaven.com/license

Use these for concrete, brick, plaster, corrugated metal, asphalt, turf-adjacent ground, and environment lighting. Prefer 1K–2K textures for the first Iris Xe performance test; keep higher-resolution source files outside the runtime build unless needed.

## Favela architecture candidates

- [Street Scene Rio Favela — Finley Searle](https://sketchfab.com/3d-models/street-scene-rio-favela-9631e0bae22343db82c44fe243af7c15) — listed as downloadable, 35.9k triangles, CC BY. Inspect the actual model, textures, topology and attribution details before deciding whether it is suitable.
- [Favela brasileira 2 — iagoArt3D](https://sketchfab.com/3d-models/favela-brasileira-2-c87942d7d3ba43648920c7f7cd451afc) — listed as CC BY and 954 triangles; likely a simple asset, so evaluate carefully rather than treating it as final-quality architecture.
- [Favela street — Buncic](https://sketchfab.com/3d-models/favela-street-306d29a9905a4c62acad68631975dfde) — described as a low-poly set of 10 houses and a pitch; appears to be a paid asset, so not assumed available for this project.

## Rules before importing

1. Confirm the exact license on the asset page and keep author/source attribution for CC BY assets.
2. Do not use CC BY-NC assets in a project that may later be commercial.
3. Inspect the downloadable file, texture quality, scale, normals, UVs, polygon count and import compatibility.
4. Do not treat a low-poly model as a final visual solution just because its subject is a favela.
5. Record each accepted asset, creator, source URL, license and any required attribution.

## Current decision

No third-party model has been imported yet. The favela architecture is the main visual risk and needs an actual quality inspection before committing to a direction.
